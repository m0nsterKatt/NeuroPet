# NeuroPet

Aplicació web per gestionar l’energia diària mitjançant una mascota virtual, pensada per a persones neurodivergents.

## Objectiu

Ajudar a:
- visualitzar l’energia disponible  
- evitar arribar al col·lapse  
- fomentar pauses i autorregulació  

## Funcionalitats

- Mascota que reflecteix el nivell d’energia  
- Sistema visual d’energia amb “cookies”  
- Registre d’activitats que sumen/resten energia  
- Frases dinàmiques segons l’estat  
- Mode ajuda amb respiració guiada  
- Grounding interactiu  
- Configuració personalitzable (recuperació automàtica, cicles de respiració, etc.)  
- Historial d’activitats  

## Tecnologies

- React  
- JavaScript  
- CSS  
- LocalStorage  

## Estructura

- /src/pages → vistes principals (Home, Help, Settings…)  
- /src/utils → lògica d’emmagatzematge  
- /src/assets → estils i recursos interns  
- /public/images → gifs de la mascota i icones d’energia  

Les imatges i animacions (gifs) es carreguen des de la carpeta public per accés directe sense necessitat d’importació.

## Concepte clau

L’app no mesura productivitat, mesura energia.

## Estat del projecte

En desenvolupament.

## Millores en un context de producte comercial

- Notificacions intel·ligents  
- Millores d’accessibilitat  
- Personalització de la mascota  
- Sistema de recompenses
- Base de dades al núvol
- Creació d'un usuari personal
